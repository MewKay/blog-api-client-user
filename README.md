# Thyblog - Public client

The single page application (SPA) front-end for the blogging site. Public front-end built with React, Vite and React Router v6.

**Links**:

- [Server](https://github.com/MewKay/blog-api-server)
- [CMS](https://github.com/MewKay/blog-api-client-author)

## Features

- List and browse published posts.
- Render posts from Markdown using react-markdown.
- Authenticated users can add comments under posts.
- URL-safe post identifiers using SQIDs.
- Custom form validator.
- Components tested with React Testing Library and Vitest.
